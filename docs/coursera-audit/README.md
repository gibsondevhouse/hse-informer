# HSE Informer — Coursera UI/UX reference package

Version 1.0 · Audited September 7, 2026 (America/New_York)

Open **[style-guide.html](style-guide.html)** for the visual reference. It includes an interactive component gallery, HSE training examples, measured Coursera values, screenshots, findings, and sources. Open it directly in a browser; the font and all assets are local.

- [Audit and implementation guide](audit-report.md): scope, evidence, component contracts, responsive rules, accessibility, decisions, and acceptance gates.
- [Implementation tokens](hse-tokens.css): proposed HSE Informer light-theme CSS variables and foundational styles.
- [Structured tokens](design-tokens.json): measured Coursera reference values separated from proposed HSE tokens.
- [Component inventory](components.json): component specifications and coverage status.
- [Evidence index](evidence/index.md): source URL, viewport, state, and evidence file mappings.
- [Validation results](validation.md): checks performed on this documentation package and remaining production checks.

The visual guide is a **design reference and local interaction demonstration**, not an implemented LMS. Its sample course, qualification, and record data are fictional. The recommendations follow the existing [product vision](../vision/phases.txt); this audit does not validate that document's regulatory interpretations.

Coursera values are an observed snapshot, not an official or exhaustive Coursera design-system export. The browser session was already signed in. Personal names were excluded from retained text measurements. Dashboard and learning captures omit personal headings; the mobile navigation capture shows the category submenu. Public marketing content was reviewed separately using web retrieval. Paid learning, checkout, authentication, full screen-reader testing, and dark-theme styling were not exercised.

Use Coursera's hierarchy and interaction conventions as a benchmark. Use HSE Informer's own identity, content, imagery, qualification semantics, and implementation. Coursera screenshots are retained as attributed research evidence and are not production assets. The bundled Source Sans 3 font is distributed under its included [SIL Open Font License](assets/OFL.txt).
