## Verification observed locally

- `web`: Svelte/TypeScript check, 21 unit tests, and Node adapter build pass. Seven migrations, the synthetic seed, and 25 tenant/evidence/reassignment/bulk-assignment integration tests passed against a fresh local Homebrew PostgreSQL 16 database. Moodle 5.3's development stack requires PostgreSQL 17; that stack was not started locally.
- `admin-app`: after merging the protected D1 pilot changes from `main`, `npm ci`, TypeScript checks, lint, 57 Node tests, and the production build passed locally. D1/Access and the other live pilot services remain unprovisioned; these local checks do not establish operational acceptance or satisfy the Refactor 001 Keycloak/Moodle gates.
- `infra/scorm`: the synthetic package structure test passes. Hosted CI also imported and launched the package in Moodle, then read tracking through documented web services. This verifies synthetic plumbing only.
- `tools/hsi-reconcile`: nine synthetic unit tests pass, including empty-export and duplicate Moodle-target rejection. No real HSI row was compared. The Moodle local-plugin test suite has not run because PHP and Moodle are absent locally.
- The compiled SvelteKit dashboard and draft Respiratory learner preview were inspected in a local browser with synthetic data. Seven Chromium browser tests pass, including multi-site recipient review, measured pagination at narrow viewports, and a draft-preview check that makes no training-record write. The bulk browser test mocks approved presentation data, then confirms that the real server rejects the seeded unapproved requirement.

Hosted [CI run 38169852450](https://github.com/gibsondevhouse/hse-informer/actions/runs/38169852450) passed all four jobs for the code at that commit: contracts/artifacts, React sample preview, SvelteKit/PostgreSQL/Chromium, and the two-Moodle/Keycloak synthetic fixture. Actual Moodle OAuth/browser account linking, the live HSE enrollment flow, cross-company learner UI access, re-enrollment/reset/version behavior, and the pilot patch acceptance still require live Gate B verification.
